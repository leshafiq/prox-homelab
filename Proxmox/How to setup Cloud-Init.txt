How to create Cloud Init (Ubuntu)

1.  Download Ubuntu (replace with the url of the one you chose from above)
    wget https://cloud-images.ubuntu.com/noble/current/noble-server-cloudimg-amd64.img

2.  Create a new virtual machine
    qm create 5000 --memory 2048 --core 2 --name ubuntu-cloud --net0 virtio,bridge=vmbr0

3.  Import the downloaded Ubuntu disk to local storage (Change local to the storage of your choice)
    qm disk import 5000 noble-server-cloudimg-amd64.img local-lvm

4.  Attach the new disk to the vm as a scsi drive on the scsi controller (Change local to the storage of your choice)
    qm set 5000 --scsihw virtio-scsi-pci --scsi0 local-lvm:vm-8000-disk-0

5.  Add cloud init drive (Change local to the storage of your choice)
    qm set 5000 --ide2 local-lvm:cloudinit

6.  Make the cloud init drive bootable and restrict BIOS to boot from disk only
    qm set 5000 --boot c --bootdisk scsi0

7.  Add serial console
    qm set 5000 --serial0 socket --vga serial0

DO NOT START YOUR VM
Now, configure hardware and cloud init, then create a template and clone.If you want to expand your hard drive you can on this base image before creating a template or after you clone a new machine.I prefer to expand the hard drive after I clone a new machine based on need.

8.  Create template.
    qm template 5000

9   Clone template.
    qm clone 5000 201 --name k3s-master-1 --full
