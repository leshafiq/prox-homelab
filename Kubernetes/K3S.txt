Oracle

# 1. Allow Kubernetes API server (Port 6443)
sudo firewall-cmd --add-port=6443/tcp --permanent

# 2. Allow all traffic from the Pod network (10.42.0.0/16)
sudo firewall-cmd --add-source=10.42.0.0/16 --permanent

# 3. Allow all traffic from the Service network (10.43.0.0/16)
sudo firewall-cmd --add-source=10.43.0.0/16 --permanent

# 4. Reload the firewall to apply the changes
sudo firewall-cmd --reload

Ubuntu

1.  If you wish to keep ufw enabled, by default, the following rules are required:
sudo ufw allow 6443/tcp #apiserver
sudo ufw allow from 10.42.0.0/16 to any #pods
sudo ufw allow from 10.43.0.0/16 to any #services

===================================================================================================================================================================================

2. To get started, first launch a server node with the cluster-init flag to enable clustering and a token that will be used as a shared secret to join additional servers to the cluster
    curl -sfL https://get.k3s.io | K3S_TOKEN=SECRET sh -s - server \
    --cluster-init \
    --tls-san=<FIXED_IP> \
    --disable=traefik \
    --disable servicelb

    (Proceed to setup kube-vip in Kube-vip-steps.txt)

3.  Get the secret token from first node and then join cluster
    sudo cat /var/lib/rancher/k3s/server/node-token
    curl -sfL https://get.k3s.io | K3S_TOKEN=SECRET sh -s - server \
    --server https://{serverip}:6443 \
    --tls-san=<FIXED_IP> \
    --disable=traefik \
    --disable servicelb

4.  to manage cluster externally, copy the content in node: /etc/rancher/k3s/k3s.yaml
    paste here: nano ~/.kube/k3s.yaml

5.  Merge into your default kubeconfig
    mkdir -p ~/.kube
    KUBECONFIG=~/.kube/config:~/.kube/k3s.yaml kubectl config view --merge --flatten > ~/.kube/config.tmp
    mv ~/.kube/config.tmp ~/.kube/config

6.  To remove a node
    shutdown the node
    kubectl drain <old-hostname> --ignore-daemonsets --delete-emptydir-data
    kubectl delete node <old-hostname>

7.  GHCR secret
    kubectl create secret docker-registry ghcr-auth \
    --docker-server=ghcr.io \
    --docker-username=<YOUR_GITHUB_USERNAME> \
    --docker-password=<YOUR_PERSONAL_ACCESS_TOKEN> \
    --docker-email=<YOUR_EMAIL_ADDRESS> # Email is optional
