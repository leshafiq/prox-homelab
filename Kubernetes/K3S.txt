1.  If you wish to keep ufw enabled, by default, the following rules are required:
    sudo ufw allow 6443/tcp #apiserver
    sudo ufw allow from 10.42.0.0/16 to any #pods
    sudo ufw allow from 10.43.0.0/16 to any #services

2. To get started, first launch a server node with the cluster-init flag to enable clustering and a token that will be used as a shared secret to join additional servers to the cluster
    curl -sfL https://get.k3s.io | K3S_TOKEN=SECRET sh -s - server \
    --cluster-init \
    --tls-san=<FIXED_IP> \
    --disable=traefik \
    --disable servicelb

3.  Get the secret token from first node and then join cluster
    sudo cat /var/lib/rancher/k3s/server/node-token
    curl -sfL https://get.k3s.io | K3S_TOKEN=SECRET sh -s - server \
    --server https://<ip or hostname of server1>:6443 \
    --tls-san=<FIXED_IP> # Optional, needed if using a fixed registration address

4.  to manage cluster externally, copy the content in node: /etc/rancher/k3s/k3s.yaml
    paste here: nano ~/.kube/k3s.yaml

5.  Merge into your default kubeconfig
    mkdir -p ~/.kube
    KUBECONFIG=~/.kube/config:~/.kube/k3s.yaml kubectl config view --merge --flatten > ~/.kube/config.tmp
    mv ~/.kube/config.tmp ~/.kube/config
